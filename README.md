# Foldesk

Foldesk 是一个原生 SwiftUI macOS 窗口收纳与工作区管理工具。

## 构建正式应用

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open dist/Foldesk.app
```

产物位于 `dist/Foldesk.app`，已进行本机临时签名，可直接双击运行。

首次运行请在“系统设置 → 隐私与安全性”中授权：

- 辅助功能：读取和控制其他应用窗口。
- 屏幕与系统音频录制：在本机生成窗口缩略图。

授权后返回 Foldesk 点击刷新。窗口标题、缩略图、历史与工作区配置只在本机处理，不会上传。

## 已实现

- 菜单栏快捷面板
- 运行应用与窗口扫描
- 搜索、聚焦、隐藏、最小化、放大/全屏、关闭窗口与正常退出应用
- 一键收起与恢复窗口位置/尺寸
- 最近 10 次收起记录
- “我的工作区”按需选择应用与具体窗口（支持拖入或从“应用程序”文件夹添加），保存窗口位置和尺寸
- 已保存的工作区可继续编辑名称、图标、成员应用和具体窗口；保存修改时更新所选窗口的布局
- 工作区卡片的“应用与窗口控制”可整体展开或收起；展开后每个成员应用及显示、最小化、放大、关闭窗口、退出应用操作位于同一行
- 最多可同时打开 3 个工作区；每个工作区拥有独立、可移动的置顶悬浮控制器
- 悬浮控制器可收成 `124 × 42` 的名称标签，多个面板会自动错开且可分别展开、移动和退出
- 进入工作区时 Foldesk 主窗口保持打开，将无关窗口最小化到 Dock，并自动显示悬浮控制器；成员默认按需打开，可为个别成员设置自动打开
- 悬浮控制器内可添加或移除成员、修改启动方式，并用左右、上下、左一右二或四宫格模板分配应用；选择槽位后会自动打开并排列对应应用
- 工作区采用可同时选择的进入/退出关系，不使用互斥的“切换”语义
- 退出单个工作区时对应悬浮窗立即消失，并可选择收起或正常关闭其独占应用；其他工作区仍在使用的共享应用会被保留
- 分屏布局：6 种预设与自定义拆分、具体窗口拖放/交换、比例和间距调整、真实窗口预览/恢复、撤销、模板持久化与一键应用
- 应用/窗口分层批量操作和安全结束工作；所有批量退出路径始终保护 Foldesk 自身
- 权限引导、排除应用与风险确认

## Finder 右键菜单扩展

Foldesk 内置一个 Finder Sync 扩展，可在 Finder / 桌面右键菜单中提供：

- 新建文件：Microsoft Excel 工作簿 / Word 文档 / 文本文档 / Markdown / 空文件
- 复制到 / 移动到：一键把选中的文件送进收藏目录
- 常用目录：打开收藏目录
- 拷贝路径、添加到常用目录
- 显示 / 隐藏所有文件
- 进入终端（在当前目录打开 Terminal）

配置入口：Foldesk 主界面左侧「右键菜单」。配置保存在
`~/Library/Application Support/Foldesk/findersync.json`，由主程序和扩展共享读取。

### 启用步骤

1. 构建并运行：`chmod +x scripts/build-app.sh && ./scripts/build-app.sh && open dist/Foldesk.app`
2. 打开 Foldesk → 左侧「右键菜单」，确认已开启。
3. 首次使用需授权扩展：
   - 打开 **系统设置 → 隐私与安全性 → 扩展 → 访达（Finder）**，勾选 **Foldesk 右键菜单**。
   - 或在「右键菜单」页点击「在系统设置中启用…」按钮直接跳转。
4. 在 Finder 窗口或桌面右键即可看到 Foldesk 的菜单项。

> 扩展与主程序均未沙盒化（ad-hoc 签名），因此可以读写任意目录。Excel / Word 模板为内置空白文件，无需安装 Office 即可生成可正常打开的文档。
