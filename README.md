# Foldesk

Foldesk 是一个原生 SwiftUI macOS 窗口收纳与工作区管理工具。

## 构建正式应用

```bash
chmod +x scripts/build-app.sh
./scripts/build-app.sh
open dist/Foldesk.app
```

产物位于 `dist/Foldesk.app`，已进行本机临时签名，可直接双击运行。

> **分发说明**：该构建使用本机自签或 ad-hoc 签名，**未经过 Apple 公证**。
> 拷到别人的机器上会被 Gatekeeper 拦下（提示“无法验证开发者”）。
> 对方可通过「右键 → 打开」或在「系统设置 → 隐私与安全性」中点击“仍要打开”放行。
> 若需正常分发，需要 Developer ID 证书并执行 `notarytool` 公证。

首次运行请在“系统设置 → 隐私与安全性”中授权：

- **辅助功能（必需）**：读取和控制其他应用窗口。没有这项权限时，收起后无法还原窗口位置、分屏和最小化都不可用。
- **屏幕与系统音频录制（可选）**：仅用于在本机生成窗口缩略图。不授权时其他功能照常可用，只是看不到预览图。

两项权限都需要在授权后**重新启动 Foldesk** 才会生效，然后回到应用点击刷新。窗口标题、缩略图、历史与工作区配置只在本机处理，不会上传。

## 已实现

- 菜单栏快捷面板
- 运行应用与窗口扫描
- 搜索、聚焦、隐藏、最小化、放大/全屏、关闭窗口与正常退出应用
- 一键收起与恢复窗口位置/尺寸
- 最近 10 次收起记录
- “我的工作区”按需选择应用与具体窗口（支持拖入或从“应用程序”文件夹添加），保存窗口位置和尺寸
- 已保存的工作区可继续编辑名称、图标、成员应用和具体窗口；保存修改时更新所选窗口的布局
- 工作区卡片的“应用与窗口控制”可整体展开或收起；展开后每个成员应用及显示、最小化、放大、关闭窗口、退出应用操作位于同一行
- 最多可同时打开 3 个工作区；每个工作区拥有独立、可移动的置顶悬浮控制器
- 悬浮控制器可收成 `124 × 42` 的名称标签，多个面板会自动错开且可分别展开、移动和退出
- 进入工作区时 Foldesk 主窗口保持打开，将无关窗口最小化到 Dock，并自动显示悬浮控制器；成员默认按需打开，可为个别成员设置自动打开
- 悬浮控制器内可添加或移除成员、修改启动方式，并用左右、上下、左一右二或四宫格模板分配应用；选择槽位后会自动打开并排列对应应用
- 工作区采用可同时选择的进入/退出关系，不使用互斥的“切换”语义
- 退出单个工作区时对应悬浮窗立即消失，并可选择收起或正常关闭其独占应用；其他工作区仍在使用的共享应用会被保留
- 分屏布局：6 种预设与自定义拆分、具体窗口拖放/交换、比例和间距调整、真实窗口预览/恢复、撤销、模板持久化与一键应用
- 应用/窗口分层批量操作和安全结束工作；所有批量退出路径始终保护 Foldesk 自身
- 权限引导、排除应用与风险确认

## Finder 超级右键

Foldesk 本机版在 app 内打包原生 **Finder Sync 扩展**。Finder 右键第一层直接显示“新建文件”：

- 新建 Word / Excel / PowerPoint / RTF / 文本 / Markdown / CSV / JSON / HTML / XML / 空文件
- 新建只在当前文件夹创建文件，不启动 Word、WPS、Finder 窗口或 Foldesk 主界面
- 复制路径 / 文件名、压缩 ZIP / 解压 ZIP、带二次确认的彻底删除
- 复制 / 移动到常用目录、用指定 App 打开、发送替身到桌面
- 在终端中打开当前目录、快速打开常用目录

Microsoft Office 和 WPS 使用相同的 `.docx`、`.xlsx`、`.pptx` 标准文件，不需要分别创建两套菜单。三种 Office 文件来自内置的真实 OOXML 空白模板；模板缺失时操作会失败并提示，不会生成损坏的 0 字节文件。同名文件自动使用“未命名 2”等名称，绝不覆盖已有文件。

旧版 25 项 macOS「服务」（NSServices）仍保留为兼容入口，其中 11 项新建类型与扩展一致。

常用目录与指定 App 在 Foldesk 主界面「右键服务」设置页里增删改，改动即时保存到
`~/Library/Application Support/Foldesk/findersync.json`，下次右键直接生效，无需重建。

### 启用步骤

1. 构建并安装：`chmod +x scripts/*.sh && ./scripts/install-local.sh`
2. 安装脚本会把旧副本移到废纸篓，只保留 `/Applications/Foldesk.app`，然后刷新注册。
3. 打开 Foldesk →「超级右键」→「打开 Finder 扩展设置」，启用“Foldesk 右键菜单”。
4. 在 Finder 当前文件夹空白处右键 → **新建文件**。

### 菜单不出现，或点了没反应？

这两种现象的原因完全不同，先跑自检分清是哪一种：

```bash
./scripts/diagnose-finder-menu.sh                  # 只检查，不改动任何文件
./scripts/diagnose-finder-menu.sh --restart-finder # 检查后重启访达以刷新扩展
```

自检会逐项确认：安装位置、扩展包与 Office 模板完整性、扩展进程是否被系统加载、
`~/Library/Application Support/Foldesk/findersync.json` 与扩展是否读到同一份配置、
以及 Gatekeeper 状态。

如果自检显示“扩展进程未运行”，通常是系统还没启用它：打开 Foldesk →
「超级右键」→「打开 Finder 扩展设置」，勾选“Foldesk 右键菜单”，然后重启访达。

改动扩展代码后必须让访达重新加载才会生效（`--restart-finder` 或手动 `killall Finder`）。

**已知限制**

- Finder Sync 菜单仅在 Finder 中出现；其他应用的右键由对应应用控制。
- 目前监听用户主目录（包括桌面、文稿、下载和子目录）以及 `/Volumes` 下的卷；系统受保护目录不支持新建。
- 本机开发签名通过目录权限例外实现直接写入；对外分发时应改用受信的后台帮助进程或用户授权的安全作用域，不应将该例外视为 App Store 方案。
- 系统只允许用户在系统扩展管理界面启用 Finder 扩展；安装脚本不会强行重启 Finder。
- 本机 ad-hoc 构建仅供本机开发使用。对外分发仍需要合适的 Apple 签名和公证。
- Finder Sync 原本面向文件同步类扩展；Foldesk 的通用菜单可用于本机，但提交 Mac App Store 前需要单独评估审核政策。
