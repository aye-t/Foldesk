制作思路：为什么要做它

不是炫技，是三个真实的日常痛点

做 Foldesk 的出发点很朴素——Mac 很好，但有两件事一直别扭：桌面窗口一多就乱，以及从 Windows 带来的“右键新建文件”习惯被砍掉了。我不想装臃肿的窗口管理器，也不想为了新建一个 Excel 先打开 Office。于是用 Agent 对话，一步步把它搭出来。

🪟

窗口洪水

写东西时开着浏览器、文档、终端、笔记、微信……切走再回来，桌面一片狼藉，找不到刚才在哪儿。

🖱️

右键被砍

Windows 里右键就能“新建 Excel / Word / 文本”，Mac 没有。每次都为建个空文件先开大软件，很烦。

🔀

场景切换

“写论文模式”“剪视频模式”“回邮件模式”要的窗口不一样，每次手动开关，重复又易漏。

产品介绍：它到底是什么

一句话：macOS 原生窗口收纳 + 工作区 + 访达右键服务

Foldesk 是一个完全本机运行的 macOS 菜单栏工具（SwiftUI 原生，无 Electron、不联网）。它做三件事：

能力解决什么依赖的权限
窗口收纳 / 恢复收起全部 → 桌面干净；恢复刚才 → 窗口回到原位置尺寸辅助功能
我的工作区把“某任务要的窗口”存成模板，一键进入 / 退出辅助功能
访达右键服务右键新建 Excel/Word/PPT/文本/MD、复制路径、压缩解压、彻底删除、复制到/移动到常用目录、用指定 App 打开无需特殊权限
隐私说明（真实）：窗口标题、缩略图、历史与工作区配置只在本机处理，不会上传。屏幕录制权限仅用于在本机生成真实窗口缩略图，可不开（不开则无缩略图，其余功能正常）。

核心功能（均为已实现）

下面每一项都能在软件里真实操作，不是概念图

📥
已实现

一键收起 / 恢复

“收起全部”把所有应用窗口藏起；“恢复刚才”一键还原到收起前的位置与尺寸。最多保留最近 10 次快照。

快捷键：收起 ⌥D · 恢复 ⌥R · 刷新 ⌘R
🎛️
已实现

窗口总控台

搜索、聚焦、隐藏、最小化、放大/全屏、关闭窗口、正常退出应用，全在一个列表里完成。

对 Word/Excel/PS 等会提示“可能未保存”，避免误关。
🗂️
已实现

我的工作区

按需选择“这个任务要的应用 + 具体窗口”存成模板；进入时自动最小化无关窗口。最多同时开 3 个工作区，可并行、可独立悬浮窗。

成员默认按需打开，可为个别应用设“自动打开”。
▦
已实现

分屏布局

6 种预设 + 自定义拆分，把应用拖进槽位即可自动排列（左右 / 上下 / 左一右二 / 四宫格等）。支持比例、间距、预览、撤销、模板持久化。

依赖“辅助功能”权限才能移动窗口。
📝
已实现

访达右键服务

在访达右键 → 服务，可新建 Excel / Word / PPT / 文本 / Markdown（内置空白模板，生成的是真 Microsoft Office 文档）、复制路径 / 文件名、压缩为 zip、解压、彻底删除；还可复制到 / 移动到常用目录、用指定 App 打开（目录与 App 在「右键服务」设置页配置，改完即时生效）。

基于 macOS「服务」机制，无需公证即可被系统发现。
🛡️
已实现

批量 & 安全结束

应用 / 窗口分层批量操作；「安全结束工作」逐个发送正常退出请求，未保存内容由原应用提示。Foldesk 自身始终保留运行。

可设置“排除应用”避免误收起特定软件。
🎬 镜头脚本 功能页用边讲边点：每个卡片对应一次真实点击。先讲“收起/恢复”（最抓人），再讲“右键新建文件”（最有记忆点），分屏最后讲（进阶）。 镜头建议：讲右键服务时，直接切到访达录一段“右键→服务→新建 Markdown”，比任何截图都强。

视频演示脚本（实操流）

按顺序录，总时长约 8–10 分钟；每段都标了镜头动作

开场：混乱桌面

实拍一堆窗口的桌面，口播痛点（对应“制作思路”页）。不碰软件。

0:00–0:40

首次运行 & 授权

打开 Foldesk → 系统设置授予「辅助功能」（收起/恢复/分屏必需）+ 可选「屏幕录制」（缩略图）。强调：不授权核心功能不可用。

0:40–1:40

一键收起 → 恢复

点“收起全部”，桌面瞬空；点“恢复刚才”，窗口回到原位。这是全片最爽点，慢动作再来一遍。

1:40–3:00

访达右键新建文件

切到访达，右键文件/空白处 → 服务 → 新建 Markdown / Excel。强调“不用开 Office”。

3:00–4:20

建一个工作区

选几个应用+窗口 → 保存为“剪视频模式”→ 退出再进入，演示无关窗口被自动收起。

4:20–6:00

分屏布局（进阶）

进工作区 → 分屏模板选“左一右二”→ 把应用拖进槽位 → 点“开始分屏”自动排布。

6:00–8:00

收尾 & 诚实交代

“安全结束工作”正常退出应用；回到“真实 vs 信息”页，说明规划中功能，引导观众关注/留言。

8:00–10:00
🎬 总导演提示 全程自己机器演示即可（软件本机已构建可跑）。录之前务必先授权“辅助功能”，否则收起/恢复会假成功、分屏不动——这是最容易翻车的点。 镜头建议：关键操作后用“鼠标圈选/放大”突出按钮，观众才看得到点哪儿。

收尾：怎么拿到 / 怎么聊

本机演示零门槛；若要发给别人用，需先过公证

现在这版是本机自签 / ad-hoc 构建，自己机器双击就能跑，适合录视频。但如果你想把 app 发给观众下载，必须先做 Apple Developer ID 公证，否则别人机器会被 Gatekeeper 拦下（提示“无法验证开发者”）。

视频里怎么措辞：“工具我先自用，配套视频教你怎么用 Agent 从零搭一个”——既诚实，又把观众引向“自己动手”的 DIY 主题，正好契合你“一也”的分享人设。

开源思路：核心能力（窗口收纳 / 工作区 / 右键服务）都基于 macOS 原生 Accessibility + NSServices，不需要上架 App Store，本地构建即用。
